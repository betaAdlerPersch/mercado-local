# Roteiro do vídeo

> O enunciado pede "até 5 minutos" na Situação 3 e "pelo menos 5 minutos" no Problema em Foco. Confirme com o tutor; este roteiro fecha em cerca de 5 minutos.

| Tempo | Cena | O que mostrar e falar |
|---|---|---|
| 0:00–0:30 | Apresentação | Seu nome, o problema (produtores que só vendem em feira) e a solução Mercado Local |
| 0:30–1:00 | Arquitetura | Estrutura do repositório, MVC (models, views, controllers, services), PostgreSQL |
| 1:00–2:30 | Jornada do cliente | Busca, filtro, montar cesta, frete grátis, erro de validação, finalizar, código, acompanhar |
| 2:30–3:15 | Área do produtor | Login, filtro por estado, avançar pedido até Entregue, tentar transição proibida |
| 3:15–4:15 | Testes e correções | Rodar `pytest` ao vivo; mostrar 2 bugs apontados pelos testadores, o antes e o depois, e os testes de regressão criados |
| 4:15–5:00 | Encerramento | O que aprendeu, próximos passos (pagamento online, cadastro de produtos), link do GitHub |

Dicas: grave a tela com OBS Studio, deixe o banco populado com alguns pedidos antes, e aumente o zoom do navegador para 125%.
